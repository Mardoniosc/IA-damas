# ADR-016 — Learning: held-out outcome models, judged by matches, not by loss

- Status: **Accepted** (G14, 2026-11-20)

## Context

G13 provides a leakage-controlled Brazilian dataset (outcome labels from self-play and
benchmark games). G14 must learn and must show whether learning helps *play*. PyTorch 2.5.1
(CUDA), NumPy and scikit-learn are already installed. The internal search runs in Python, so
its evaluation must be cheap per node.

## Decision

1. **Models** predict P(outcome for the side to move), with draws as 0.5 targets:
   - logistic models (NumPy Newton, L2 chosen on `val`) on CHEAP features (men, kings, tempo,
     center, back_rank) or FULL features (+ mobility, runaways);
   - a **residual** model: the baseline hand eval plus learned positional terms;
   - an **MLP** (PyTorch) on 128 piece-square inputs (board oriented to the side to move), for
     comparison only (too slow per node for the Python search).
2. **Two separate evaluations**:
   - held-out `test` log-loss / Brier / decisive accuracy;
   - **matches** (G12 machinery) of learned-eval search vs baseline-eval search, at **equal
     depth** (evaluation quality) and **equal time** (including slowdown).

   **A model is adopted only if the matches show a significant gain** (95% interval above 0).
3. **Pluggable evaluator** in `Searcher` and the Hub engine (`eval-model` parameter). Committed
   models are small JSON files carrying their training provenance (dataset manifest SHA-256, L2,
   test metrics).

## Consequences (G14 outcome)

- All learned models predict outcomes better than the hand eval on held-out data (the MLP is
  best). **None is adopted as default**:
  - the pure linear model (which learned "king ≈ man") plays worse at equal time;
  - the residual model shows a possible small gain (+27 Elo, LOS 0.84 over 128 games) that is
    not significant.
- The baseline evaluation remains the default. The residual model is available opt-in for
  further testing.
- The gap between "predicts outcomes" and "plays better" is the main lesson. Outcome labels
  from games between weak engines under-value promotion. Better data (deeper self-play, more
  games) or search-aware training targets are the next steps.
