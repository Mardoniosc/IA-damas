# ADR-004 — Licensing and third-party binary policy

- Status: **Accepted** (G1, 2026-11-20). This is not legal advice; owner-level legal review is
  recommended before any public distribution.

## Context (verified in G1)

| Component | Terms found | Evidence |
|---|---|---|
| Scan 3.1 / lidraughts fork | GNU GPL v3 | `license.txt`, readme; GitHub `spdx_id: GPL-3.0` |
| Kingsrow (all builds) | "free downloads" / "free programs". **No license text or redistribution terms found** on the pages examined | edgilbert.org (K1–K4) |
| Kingsrow endgame databases | hosted on Mega. **No terms found** | K2–K4 |
| CheckerBoard source (eygilbert/CheckerBoard) | **no license file detected** by GitHub | GitHub API |
| egdb_8x8 (Kingsrow egdb driver source) | Boost Software License 1.0 | GitHub API |
| py-draughts 1.10.1 | GPL v3 | package metadata |

## Decision

1. **No third-party engine binaries, data files (books, bitbases, egdbs) or source code are
   committed or redistributed.** Each user obtains engines from the author under the
   author's terms and points the platform at them via configuration. `engines/`, `*.exe` and
   `*.dll` are git-ignored.
2. **Scan** is used only as an unmodified, separate program communicating over stdin/stdout
   (ADR-002). If Scan binaries are ever distributed with the platform, GPL v3 obligations apply
   to that distribution (license text, corresponding source). A modified Scan (for example an 8x8
   port, ADR-005 option B) is a GPL v3 derivative. If it is distributed, its source must be
   published under GPL v3. It must live in a separate repository, not in this one.
3. **Kingsrow** is treated as "all rights reserved, free to download for personal use" until the
   author states otherwise. Before any redistribution, bundling, hosted service or commercial use,
   obtain written permission from Ed Gilbert.
4. **CheckerBoard source** is not copied. The platform implements its own host for the
   documented DLL calling convention, written from the interface description, not by copying
   the header file.
5. **GPL tools as oracles** (py-draughts): allowed as optional dev-only test tools, invoked in
   test code. They are never imported by `damas_ai` runtime code and never listed in runtime
   dependencies.
6. This project's own license is an **owner decision** that is still open. Note that choosing a
   non-GPL license is compatible with points 1, 2 and 5 as written.

## Consequences

- Setup is manual per machine (documented in the PoC report and the README).
- Benchmarks and published results must cite engine versions and must not ship engine data.
