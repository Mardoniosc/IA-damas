# ADR-010 — Internal engine served over Hub; adaptive escalation on divergence

- Status: **Accepted** (G8, 2026-11-20)

## Context

After G7 the platform had no Brazilian evidence source: no external engine plays Brazilian
(ADR-005). G7 also showed that divergences are partly noise (time-limited, non-deterministic
searches) and partly stable. G8 "Adaptive Search" must provide (a) the platform's own search and
(b) a way to spend effort where engines disagree.

## Decision

1. **Internal engine (`damas_ai.search`).** Negamax alpha-beta with iterative deepening, a
   transposition table (Zobrist keys from G2), capture extension (captures are never "quiet"),
   killer and history ordering, and repetition-as-draw. **Moves come only from the Rules Core**,
   so the engine is legal by construction (ADR-001).
2. **Baseline evaluation, explicitly untuned**: material (man 100, king 300, in hundredths of a
   man) plus advancement (+4 per row). It is a reference to beat (G14), not a claim of quality.
3. **Score encoding as Scan**: evals in men clamped to ±80, wins as `100 − plies/100`, side to
   move's perspective. Profile `damasai` has depth, nodes and move-time limits.
4. **Served over Hub v2 in its own process** (`python -m damas_ai.search.hub`, param
   `variant=brazilian|international`). It gets the same isolation, kill-ability, conformance,
   pool, consensus and adaptive treatment as Scan and Kingsrow. There is no special-case code
   path.
5. **Deterministic at fixed depth.** With a cleared table (the pool sends `new-game` before
   each request), fixed-depth results repeat exactly. This addresses R20 for this engine.
6. **Adaptive escalation (`damas_ai.adaptive`).** Run consensus. While the class is
   `preference`/`outcome_conflict` or a proof gap exists, multiply the limit (time × factor,
   nodes × factor, depth + log2(factor)) and run again, up to `max_steps` or a ceiling. The full
   trajectory is kept.

## Consequences

- Pure Python: about 25–30k nodes/s (depth 8–9 per second on 8x8, depth 7 on 10x10). It is
  much weaker than Scan or Kingsrow (G8 evidence). A faster board representation would need
  cross-checking against the Rules Core (ADR-006).
- Brazilian analysis now has **one** source. Brazilian consensus still needs a second,
  independent one. Two configurations of the same engine are not independent evidence.
- Adaptive escalation multiplies engine time on divergent positions (up to 1 + 2 + 4 = 7× the
  base for factor 2 and 3 steps).
