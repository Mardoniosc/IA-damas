# ADR-009 — Consensus by cross-evaluation in each engine's own units

- Status: **Accepted** (G7, 2026-11-20)

## Context

Scan and Kingsrow report scores on different, undocumented-relation scales. G7 measured
Kingsrow ≈ 0.64 × Scan on 241 paired evals (r = 0.988), and the two engines use different win
encodings (≈100 vs ≈40). Comparing raw numbers across engines would therefore be wrong (R08).
G7 must still say whether a disagreement between engines *matters*.

## Decision

1. **Cross-evaluation.** When engines propose different moves (`cross_check="disagreement"`,
   the default; `always` and `never` also exist), every engine evaluates every proposed move by
   searching the position after it with the same limit and the same move history.
2. **Values stay intra-engine.** A score becomes a utility for the mover, in that engine's own
   units:
   - eval `v` gives `v`;
   - a proven win at distance `d` gives `+(10000 − d)`;
   - a proven loss gives `−(10000 − d)`;
   - a move that ends the game gives a terminal win.

   Scores are only converted when the profile knows the score perspective (side to move).
   Otherwise the value is `unknown`, never guessed.
3. **Regret** of a candidate for an engine = that engine's best utility − the candidate's
   utility (own units). **Tolerance is per engine**, default 0.10 in each engine's units. The
   default is **provisional**; the classification is sensitive to it (see the G7 report).
4. **Classification per position:** `none`, `equivalent_alternatives`, `preference`,
   `outcome_conflict`, `incomplete`. Only **contradictions** are conflicts: win vs loss, or a
   proven result vs an eval that does not favour the same side.
5. **`proof_gap` flag** (G7 finding): one engine proves a result that another only evaluates in
   the same direction. In the first real run all 14 cases initially labelled "conflict" were
   of this kind, which is why it is separated from contradictions.
6. **Cross-engine scale relation is descriptive only** (`fit_scale`). It is not used for
   decisions. Calibration against game outcomes is G12/G13.
7. **Sequential is the default mode for consensus** (ADR-008: equal conditions).
8. **Kingsrow multi-PV is not used.** Cross-evaluation gives an engine-agnostic ranking of the
   candidate set; multi-PV would apply to one engine only. Revisit in G8/G9.

## Consequences

- Cost: 2 to 3 times more engine time on disagreeing positions (each engine × each candidate).
- Time-limited searches are non-deterministic. Repeated runs can classify a few positions
  differently (G7: 203 vs 213 unanimous out of 300). Consumers must treat single-run labels as
  samples, and reproducibility records must include the limit and the engine versions (they do).
